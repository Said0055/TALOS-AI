TALOS AI — сборка Windows-приложения

ВАЖНО
- Интерфейс сохранён из вашего исходного HTML без переделки.
- Этот пакет — исходный проект для сборки установщика, а не готовый .exe.
- В текущей среде нет Windows-сборщика/Wine, поэтому готовый Windows EXE здесь честно не скомпилирован.

КАК ПОЛУЧИТЬ TALOS-AI-Setup.exe БЕЗ CMD НА СВОЁМ ПК
1. Создайте репозиторий на GitHub (можно Private).
2. Загрузите в репозиторий ВСЕ файлы и папки из этого ZIP.
3. Откройте вкладку Actions.
4. Выберите "Build TALOS AI for Windows".
5. Нажмите "Run workflow".
6. Когда сборка завершится зелёной галочкой, откройте запуск сборки.
7. Внизу страницы скачайте Artifact "TALOS-AI-Windows-Installer".
8. Распакуйте скачанный архив и запустите TALOS-AI-Setup.exe.

После установки появятся ярлык в меню Пуск и ярлык на рабочем столе.
Установщик позволит выбрать папку установки.

ПЕРВЫЙ ЗАПУСК
Откройте настройки TALOS AI и введите свой OpenRouter API key непосредственно
в приложении. Не отправляйте ключ в чат и не добавляйте его в GitHub.

ПРИМЕЧАНИЯ
- История/настройки хранятся в профиле приложения Electron на этом компьютере.
- Видеогенерация и полноценное управление Windows не добавляются одной упаковкой:
  в исходном HTML эти функции требуют отдельной реализации и проверки.
- Для обновления приложения загрузите новую версию исходников в репозиторий
  и снова запустите workflow.

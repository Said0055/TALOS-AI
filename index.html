Готово
Как настроить: В Настройках укажите ключ для изображений. Для OpenAI: Base URL https://api.openai.com/v1, модель dall-e-3. Для OpenRouter: URL https://openrouter.ai/api/v1, модель openai/dall-e-3 (нужен доступ к image models). Размеры DALL·E 3: только 1024×1024, 1792×1024, 1024×1792.
Генерация видео
Подключение: Нужен провайдер видео (Runway, Luma, Kling и т.д.) — укажите Base URL и ключ в Настройках. Большинство API асинхронные.
Работа с документами

Загрузить файл

PDF, TXT, MD, CSV, JSON, код, таблицы. TALOS прочитает и сможет пересказать, проанализировать или ответить по содержимому.

Как пользоваться: загрузите файл здесь или через 📎 в чате, затем спросите: «перескажи», «найди ошибки», «сделай выводы по таблице».
Управление компьютером
Ограничение браузера: HTML-страница не может открывать программы и выполнять команды на вашем ПК — это запрещено из соображений безопасности. Ниже — безопасный режим: TALOS предлагает команды, вы копируете и запускаете сами (или в терминале).

Что умею в этом режиме

  • Подсказать команды для Windows / macOS / Linux
  • Найти, как открыть программу или файл
  • Составить скрипт (PowerShell, bash) под вашу задачу
  • Объяснить, что делает команда, до запуска
